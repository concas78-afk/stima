# Registro delle Attività di Trattamento (art. 30 GDPR)

> ⚠️ Bozza dimostrativa — da mantenere aggiornato. QuickCraft agisce sia come **Titolare** (per i dati degli utenti) sia come **Responsabile** (per i dati dei clienti finali degli utenti).

---

## A) Trattamenti di cui QuickCraft è TITOLARE

| Voce | Dettaglio |
|---|---|
| **Trattamento** | Gestione account utenti artigiani |
| **Finalità** | Erogazione del servizio, autenticazione, assistenza |
| **Dati** | Nome, email, telefono, dati aziendali (P.IVA, IBAN) |
| **Interessati** | Utenti (artigiani/professionisti) |
| **Base giuridica** | Contratto (6.1.b) |
| **Destinatari** | Hosting (UE), eventuali sub-fornitori |
| **Conservazione** | Durata del rapporto + 10 anni per dati fiscali |

| Voce | Dettaglio |
|---|---|
| **Trattamento** | Marketing e comunicazioni |
| **Finalità** | Invio newsletter/offerte |
| **Dati** | Email, nome |
| **Interessati** | Utenti che hanno prestato consenso |
| **Base giuridica** | Consenso (6.1.a) |
| **Conservazione** | Fino a revoca del consenso |

## B) Trattamenti di cui QuickCraft è RESPONSABILE (per conto degli artigiani)

| Voce | Dettaglio |
|---|---|
| **Trattamento** | Gestione CRM e fatturazione elettronica |
| **Finalità** | Generazione/invio fatture FatturaPA, gestione preventivi e clienti |
| **Dati** | Anagrafiche e dati fiscali dei clienti finali (P.IVA, CF, codice destinatario, PEC) |
| **Interessati** | Clienti finali degli artigiani |
| **Base giuridica** | Obbligo legale (6.1.c) + contratto (6.1.b) |
| **Sub-responsabili** | Provider API FE accreditato SDI, conservatore a norma, hosting UE |
| **Conservazione** | 10 anni (obbligo fiscale) |
| **Misure** | Cifratura at-rest/in-transit, 2FA, log accessi, minimizzazione |

---

*Nota: aggiornare il registro a ogni modifica dei trattamenti o dei sub-responsabili.*
